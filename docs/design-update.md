# Modern visual redesign

The user requested a substantially more modern design after reviewing the original-theme reconstruction. This replaces the old visual styling while preserving the published business information, all 478 catalogue entries, article paths, contact details and careers links.

The design uses warm off-white surfaces, charcoal, vermilion red, strong type, a locally rendered SVG hardware scene, category icon cards, testimonials, and accessible native FAQ disclosures. Main-page visuals and typography no longer depend on WordPress media or external fonts. Illustrated hardware and category symbols are decorative, not product photographs. Brand names use styled text rather than claiming to reproduce the original logo artwork.

Search, category filtering, pagination, persisted enquiries, downloadable lists, and email preparation remain functional. Category links enter the catalogue with the chosen filter. Content from the WordPress export is historical and does not establish current stock or vacancies. The supplied Gmail remains the enquiry destination.

Preview retains noindex directives until approved for public search indexing. Netlify production deployment is managed by the user's GitHub integration; a push does not itself confirm deployment success.

## Readability and simplification pass

Removed the top promotional bar, repeated eyebrow captions, category numbering, repeated product instructions and the extra brand strip on the product page. Increased body and control type, reduced oversized headings, standardized category icon colors, and replaced ambiguous selected styling with a dark filled button, checkmark and outlined selected card. Mobile products use a single column for readable names and full-size actions.

Section entrances, the hardware illustration, dialog opening, enquiry tray, and button feedback use short, finite animations. Content remains visible without JavaScript animation, and prefers-reduced-motion disables both CSS and observer-driven animations.

Fortune, Titan and Cobra image URLs from the original WordPress export replace text-only logos on the homepage. They correspond to the user's supplied reference. The source host denies downloads from this cloud environment, so the logos are externally hosted, with plain brand-name fallbacks on load failure. Their appearance on the deployed site has not been verified; local copies are still needed for independent hosting.
